# Commercial Operations Kit

Pacchetto operativo per accelerare vendita, onboarding e attivazione clienti paganti.

## Contenuto

1. `discovery-call-script.md`
Script guidato per call di scoperta commerciale.

2. `proposal-template.md`
Template proposta economica e commerciale.

3. `sales-email-sequence.md`
Sequenza email demo -> trial -> paid.

4. `onboarding-day0-30.md`
Piano operativo onboarding cliente nei primi 30 giorni.

5. `pilot-agreement-checklist.md`
Checklist per chiudere pilota e convertire a contratto annuale.

## Come usarlo

1. Eseguire la discovery call usando lo script.
2. Inviare proposta entro 24 ore.
3. Attivare sequenza email in base alla fase funnel.
4. Eseguire onboarding day 0-30 con owner assegnato.
5. Chiudere con review pilota e proposta annuale.

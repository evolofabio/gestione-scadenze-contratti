# Support SLA Playbook

## Canali Supporto

1. Email supporto: da configurare.
2. Ticketing: consigliato (Freshdesk, Zendesk o alternativa).
3. Canale urgente P1: numero dedicato o escalation diretta.

## Finestra Operativa

1. Supporto standard: lun-ven, orario ufficio.
2. Incidenti P1: reperibilita estesa.

## Classificazione Ticket

1. P1: servizio non disponibile o blocco totale.
2. P2: funzionalita critica degradata.
3. P3: bug non bloccante.
4. P4: richiesta informativa o miglioramento.

## SLA Obiettivo

1. P1: prima risposta <= 30 minuti, workaround <= 4 ore.
2. P2: prima risposta <= 4 ore lavorative, fix/workaround <= 2 giorni lavorativi.
3. P3: prima risposta <= 1 giorno lavorativo.
4. P4: prima risposta <= 2 giorni lavorativi.

## Workflow Ticket

1. Apertura ticket con categoria e impatto.
2. Triage iniziale e assegnazione owner.
3. Aggiornamenti periodici al cliente.
4. Chiusura con riepilogo causa/soluzione.
5. Se ripetitivo, creare action item di prodotto.

## KPI Supporto

1. First response time medio.
2. Tempo medio risoluzione.
3. Tasso riapertura ticket.
4. CSAT post-intervento.
